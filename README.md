# Look 1 英文複習站

小一英文（National Geographic Learning《Look 1》）在家複習用的網站：自然發音拆音節單字、劍橋美式發音、四線格寫字練習、課文導讀、句型練習和模擬小考。

老石自製、非官方，與出版社無關。網站內容為自編的摘要與題目，不含課本原文。

用 iPad 的 Safari 打開網站，按「分享」→「加入主畫面」，就能像 App 一樣全螢幕使用。

## 方塊單字世界（遊戲版）

`blocks/` 資料夾是同一套單字的遊戲版：挖礦場拼字、工作台蓋東西（Unit 5 組機器人、Unit 9 穿搭秀）、每個單元自己的小遊戲（顏色地板、教室尋寶、幸運方塊、小郵差、拍全家福、暴風雨躲房間、小鎮計程車、趕動物、穿搭比賽、開小店、海灘釣魚、公園跑酷；Unit 5 是夜晚守衛打大魔王）、字母雨接字母、用寶石在兌換區設計機器人夥伴。網址是網站後面加上 `blocks/`。iPad 橫放和電腦螢幕會改成左右兩欄，一題放在一個畫面裡。

角色和場景都是原創的方塊風格，跟任何現有遊戲、教科書角色無關。進度只存在使用的那台裝置的瀏覽器裡。
